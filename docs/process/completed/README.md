# Completed tasks

This directory is the append-only record of finished work. It replaces the
former single-file `docs/COMPLETED.md`.

## Append rule

- Record an outcome in the file for its **outcome date** (the date the task
  finished), not the date it started.
- Create a new `YYYY-MM-DD.md` file only when the first outcome of that date is
  recorded. Do not pre-create empty date files.
- Append new rows and sections to the **end** of the file. Never rewrite,
  reorder, or delete existing entries.
- Historical entries stay verbatim. Do not fix old links, old paths, or old task
  states inside preserved history — they are evidence of what was believed and
  written on that date.
- `archive.md` holds migrated history that predates this split (one-time
  STATUS.md reconciliation and the preserved documentation log). It is frozen
  and receives no new entries.
